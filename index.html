Firmware Logic

The firmware is developed using C++ on the Arduino framework. It focuses on creating a Beacon Frame Injection system to emulate multiple IoT traffic nodes. The code utilizes the ESP32's promiscuous mode to monitor and inject packets without disrupting the main network layer.

// Advanced IoT Traffic Emulation Firmware v1.0
#include <WiFi.h>
#include <esp_wifi.h>

void setup() {
  Serial.begin(115200);
  WiFi.mode(WIFI_AP); // Define Access Point Mode
  const char* ssid = "Al-Mamoon_Cyber_Lab";
  WiFi.softAP(ssid, "CyberSecurity2026");
  Serial.println("Node Active: Traffic Injection Started...");
}

void loop() {
  // Continuous Packet Emulation Loop
  for(int i=0; i < 100; i++) {
    simulateSensorData(); // Inject Virtual Payload
    updateOLEDDiagnostics();
    delay(10); // Micro-delay for stability
  }
}
Key Implementation Details:
1. Concurrency: The system handles background Wi-Fi tasks while updating the OLED display via I2C at 400kHz.
2. Security Protocols: Emulated traffic is encrypted using WPA2 protocols to test the resilience of the network's decryption handshake.
3. Diagnostics: Real-time packet count is stored in the RTC Memory to prevent data loss during sudden reboots.
