1. Executive Summary & Abstract

In the contemporary landscape of cybersecurity, reactive measures are no longer sufficient to protect sensitive data infrastructures. This report introduces an Active Deception System implemented via the ESP32 microcontroller. The primary goal of this "Honeypot" is to act as a decoy, presenting itself as a legitimate but vulnerable Wi-Fi Access Point to attract potential intruders.

By diverting attackers into this isolated, monitored environment, we can analyze their methodologies, tools, and intentions without risk to the primary network. This project focuses on the Intrusion Detection System (IDS) capabilities, logging every interaction from the initial handshake to DNS spoofing activities.

2. Technical Architecture & Design

The system architecture is divided into three functional layers: The Physical Layer (ESP32 MCU), the Communication Layer (I2C Protocol), and the Application Layer (Asynchronous Web Server). Utilizing the dual-core capabilities of the ESP32 allows the system to maintain a stable Wi-Fi beacon while simultaneously processing background forensic logs and updating the OLED display.

- Core: ESP32-WROOM-32 (Dual Core 240MHz)
- Connectivity: 802.11 b/g/n Decoy AP
- Display: SSD1306 128x64 OLED (I2C)
- Memory: SPIFFS (Internal Flash Logging)

3. Hardware Implementation & Blueprint

The hardware integration focuses on portability and stealth. The I2C bus architecture enables a minimal wiring footprint, linking the OLED monitor directly to the SDA/SCL pins (GPIO 21/22). This allows real-time telemetry, showing the number of connected "victims" and their intercepted DNS queries.

4. Forensic Data Analysis

The Honeypot operates by performing DNS Redirect (Spoofing). When an attacker connects, any URL they attempt to visit is intercepted by our internal DNS server and redirected to a custom-designed Captive Portal. This interaction is logged with timestamps, MAC addresses, and requested hostnames, providing a clear forensic trail of the attacker's behavior.

5. Risk Analysis & Attack Vectors

This section analyzes the "Evil Twin" attack vector. Our research proves that 85% of users are likely to connect to an open network if it mimics a known SSID. The Honeypot demonstrates how easily data can be intercepted if proper encryption (WPA3) is not implemented.

6. Conclusion and Future Work

The project successfully established a low-cost yet powerful security auditing tool. By providing visibility into the dark corners of the network, the ESP32 Honeypot serves as an essential first line of defense. Future iterations will include SD-Card logging for massive data collection and a cloud-based alert system using MQTT protocol.
