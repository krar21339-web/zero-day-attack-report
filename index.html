01 // Introduction & Index

The Decoy Strategy

Our Honeypot is a proactive cybersecurity tool designed to act as a decoy. It lures potential attackers into a simulated network environment to log their behaviors without compromising real systems.

  • Dynamic SSID Spoofing
  • Real-time Intrusion Logging
  • Forensic Data Capturing
02 // Technology Stack

Hardware Components

We utilized low-cost yet powerful modules to build a portable defense station. Each part was selected for its specific protocol compatibility.

ESP32 Core
OLED Screen
Custom Circuit
  • ESP32: Dual-core Wi-Fi & Bluetooth module.
  • SSD1306: 0.96 inch I2C OLED for local monitoring.
  • I2C Bus: For seamless communication between modules.
03 // Programming & Ethics

C++ / Arduino Logic

The system is built on an Asynchronous model. It manages DNS spoofing and DHCP assignments without blocking the CPU.

Ethical Boundry: While this hardware can be programmed for advanced 'De-authentication' or 'Man-in-the-Middle' attacks, our implementation is strictly for auditing and education.

04 // Security Risks

The Victim's Perspective

Connecting to an open network exposes users to massive risks. Once connected to our Honeypot, a victim faces:

  • Evil Twin Attack: User thinks it's a safe public Wi-Fi.
  • DNS Redirection: All traffic sent to fake login portals.
  • Data Theft: Clear-text passwords recorded instantly.
05 // Conclusion & Benefits

The Importance of Defense

Our project proves that Honeypots are vital for modern security infrastructure. They provide early warning systems that are low-cost, efficient, and highly effective against common Wi-Fi exploits.
