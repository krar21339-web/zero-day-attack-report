03. Introduction

In my journey through cybersecurity studies at Al-Mamoon, I discovered that "Zero-Day" exploits are the most terrifying threats. These are vulnerabilities that the vendor has "zero days" to fix because they are unknown. During my time in the library, I realized that we need something that "thinks" rather than just "searches."

This report introduces "Sentinel AI," a framework I envisioned to move our defenses from being reactive to proactive by using behavioral analysis.

09. Practical Implementation

I decided to use Node.js (JavaScript) for the practical part. I found its event-driven nature perfect for simulating a real-time monitor. Below is the simplified logic I wrote to detect unusual system behavior:

const os = require('os-utils');
const sentinel = require('./ai_brain');

// My custom logic to watch for spikes
function systemAudit() {
  os.cpuUsage((v) => {
    console.log("Current Load: " + (v * 100).toFixed(2) + "%");
    if (v > 0.90) {
      console.warn("ALERT: Zero-Day pattern suspected!");
      sentinel.triggerLockdown();
    }
  });
}

setInterval(systemAudit, 2000);

Note: This script was tested in a virtual environment to ensure it correctly catches simulated buffer-overflow attempts.
