01 // Introduction & Map

The Decoy Blueprint

This project addresses unauthorized network intrusions. By creating a deceptive Access Point, we can isolate and analyze hacker behaviors without risking primary data.

02 // Technology Stack

Hardware Components

We utilized high-performance components for real-time monitoring:

  • ESP32: Dual-Core MCU for Wi-Fi simulation.
  • OLED Display: I2C interface for forensic logging.
  • Custom Map: Routing integrated components.
03 // Programming Logic

Async C++ Firmware

Our code runs on an asynchronous non-blocking model. It manages a DNS server and Captive Portal simultaneously.

*ETHICAL WARNING: The hardware capability for active packet injection was restricted to defensive auditing only.

04 // Security Risks

The Evil Twin Trap

Connecting to networks without encryption exposes victims to:

  • Phishing for credentials via DNS redirection.
  • Man-in-the-Middle (MitM) data sniffing.
05 // Conclusion

Project Outcome

The ESP32 Honeypot successfully demonstrates that visibility is the first step of defense. This system provides a scalable, low-cost method for network administrators to detect unauthorized entry early.
