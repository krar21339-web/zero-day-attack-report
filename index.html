Introduction: Strategic Deception

Concept & Philosophy

A Honeypot is a proactive security tool designed to lure attackers away from real assets into a controlled environment. By mimicking a vulnerable 802.11 Access Point, the ESP32 captures interaction patterns that reveal modern attack vectors. This project shifts cybersecurity from passive defense to active threat intelligence gathering.

Protocol Stack Analysis

The system relies on DNS Spoofing (Port 53) to intercept domain requests. Utilizing the Asynchronous Web Server library, it handles concurrent HTTP requests to present a Captive Portal. The I2C protocol facilitates high-speed data flow between the MCU and the OLED display, maintaining a clock frequency of 400kHz.

Cyber Risk Analysis

The Evil Twin Attack

Our project illustrates the Social Engineering risks present in public Wi-Fi infrastructures. Attackers clone legitimate SSIDs (e.g., "Airport_Free") to trick users into connecting.

Once connected, the Man-in-the-Middle (MitM) position allows for absolute traffic interception, certificate spoofing, and credential harvesting.
