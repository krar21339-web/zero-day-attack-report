01 // CONCEPTUAL PHILOSOPHY

In modern network security, the paradigm has shifted from "Preventative" to "Proactive." The ESP32 Honeypot represents a critical evolution in localized threat detection. By deploying a low-cost, high-efficiency decoy, we create a Digital Mirage that lures potential intruders into a controlled environment.

This system utilizes the core principles of Deception Technology. Instead of waiting for a firewall breach, the Honeypot presents an intentional vulnerability. This allows us to capture the Attacker's Fingerprint—including their MAC address, intent, and methodology—before they can touch actual sensitive data.

The project leverages the dual-core architecture of the ESP32 to maintain a stable Wi-Fi beacon while simultaneously processing background forensic logs, ensuring no data is lost during high-frequency intrusion attempts.

02 // SYSTEM ARCHITECTURE & BLUEPRINT

The blueprint of our system follows a modular I2C-driven approach. This architectural choice minimizes physical wiring while maximizing data throughput between the MCU and peripheral displays. The data-flow is mapped from the Wi-Fi Radio Stack through the Asynchronous Event Handler to the local OLED Telemetry.

Figure 2.0: Structural blueprint and data-flow logical mapping.

- Bus Protocol: I2C (SDA/SCL Line Integration)
- OS Model: FreeRTOS (Asynchronous Dual-Core Tasking)
- Memory Management: SPIFFS Forensic Storage Partition

The integration shown in the blueprint ensures that the Captive Portal remains responsive even when the DNS server is under spoofing-related stress, a common issue in single-core IoT devices.
