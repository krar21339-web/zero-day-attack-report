01. INTRODUCTION EMULATION OVERVIEW

EXECUTIVE SUMMARY

The primary goal of this project is to implement a robust framework for Emulating IoT Traffic using ESP32 microcontrollers and Raspberry Pi. This system simulates real-world sensor data streams to analyze network behavior under various conditions. In cybersecurity, this is essential for testing firewall resilience and detecting potential anomalies in IoT device communication.

HARDWARE IMPLEMENTATION

1. ESP32 Microcontroller

Acts as the generator of synthetic data. It uses Wi-Fi to transmit emulated traffic packets to the server, mimicking multiple IoT devices simultaneously.

2. OLED Display (SSD1306)

Provides a localized monitor for the researcher to view connection logs, IP status, and packet counts in real-time without external monitors.
