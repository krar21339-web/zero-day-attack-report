01. Executive Introduction

The Honeypot Technology represents a proactive defense mechanism in the field of Network Security. This project focuses on the design and deployment of a hardware-based honeypot using the ESP32 Microcontroller. Unlike traditional firewalls that block traffic, our system invites interaction to log and analyze the behavior of potential intruders.

By simulating a legitimate Open Wi-Fi Access Point, we utilize Captive Portal technology to intercept unauthorized connections. This research explores the integration of embedded systems with cybersecurity protocols to provide real-time monitoring and threat intelligence gathering.

02. Technical Hardware Architecture

Our system is built upon high-performance, low-power components designed for continuous operation. The core processing is handled by the ESP32, which manages both the network stack and the user interface logic.

1. ESP32 NodeMCU: Dual-core CPU with integrated 2.4GHz Wi-Fi and Bluetooth. It acts as the DNS server and Web host.

2. SSD1306 OLED (128x64): A high-contrast display used for real-time telemetry, showing IP addresses, connected clients, and captured data packets.
[Insert ESP32 Pinout Diagram Here]

The communication between the MCU and the display is established via the I2C (Inter-Integrated Circuit) protocol, ensuring minimal wiring complexity using only two signal lines: SDA (Data) and SCL (Clock).

03. Software Engineering & Logic

The software architecture follows an asynchronous model to handle multiple concurrent connections. Using the Arduino Framework (C++), we implemented a custom DNS handler that redirects all 'A-record' queries to the local IP address of the ESP32 (192.168.4.1).

04. Cybersecurity Risk Analysis

This implementation demonstrates the Evil Twin Attack vector. In a real-world scenario, an attacker mimics a trusted SSID (e.g., "University_Staff_WiFi"). Users, seeking connectivity, connect to this rogue AP. The system then serves a Social Engineering page that requests sensitive credentials.

This section highlights the critical importance of HTTPS and certificate validation. Since our honeypot operates on HTTP, it showcases how easily unencrypted data can be sniffed in transit.
