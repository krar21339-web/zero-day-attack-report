• OLED Display: Real-time monitoring of captured credentials.
• I2C Bus: Specialized serial communication for data telemetry.

02. Embedded Programming Logic

The software is designed to intercept DNS queries. When a victim connects, the system redirects all traffic to a custom Captive Portal hosted locally on the MCU's flash memory.

Utilizing Asynchronous Web Serving, the device can maintain a stable connection while simultaneously logging data to the Serial monitor and OLED screen.

03. Cybersecurity Risk Scenarios

This report demonstrates the Evil Twin Attack. By broadcasting a familiar SSID, the attacker lures users into a fake login environment. This showcases why open public networks are inherently dangerous.

04. Experimental Results

Final tests showed 100% success in redirection and 0% data loss during packet capture. The system is capable of operating for extended periods using a standard 5V power supply.
