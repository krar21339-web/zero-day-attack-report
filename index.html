01 // THEORETICAL FOUNDATION

The Strategy of
Active Deception

Modern cybersecurity requires a paradigm shift from passive defense to Active Engagement. This project explores the deployment of a "Honeypot"—a deceptive network node designed to mimic high-value targets while isolating and profiling potential intruders.

By utilizing the ESP32 Microcontroller, we have engineered a portable, low-power forensic hub capable of simulating vulnerable access points. This allows security administrators to capture the attacker's methodology, tools, and intentions without compromising the core infrastructure.

02 // HARDWARE ARCHITECTURE

Hardware-Software
Orchestration

The core hardware revolves around the ESP-WROOM-32 module, chosen for its Dual-Core architecture. While Core 0 manages the Wi-Fi radio stack and decoy beacons, Core 1 is dedicated to real-time Forensic Data Analysis.

I2C Interface

Seamless data flow to SSD1306 OLED displays via GPIO 21/22 for live telemetry.

Asynchronous Ops

Handling multiple intrusion attempts concurrently without system latency or crash.

03 // FIRMWARE LOGIC & SCRIPTING

Forensic Engine Implementation

The system is programmed using an optimized C++ framework, utilizing low-level Wi-Fi libraries to manipulate packet headers and redirect unauthorized DNS requests.

#include <WiFi.h>
#include <DNSServer.h>

void initHoneypotNode() {
  WiFi.mode(WIFI_AP);
  WiFi.softAP("AL-MA'MOON_GUEST_WIFI"); 
  
  // Start Deception Engine on Port 53
  dnsServer.start(53, "*", IPAddress(172, 0, 0, 1));
  Serial.println("[CORE]: Forensic Logging Active...");
}

void loop() {
  dnsServer.processNextRequest();
  if (detectIntruder()) {
    captureMACAddress();
    pushToLiveDashboard();
  }
}

This code structure ensures that every Packet Ingress is inspected. By logging the MAC address and device signatures, we build a comprehensive profile of the threat actor, allowing for adaptive defensive measures.
