01 // PROJECT OVERVIEW & ABSTRACT

The rapid proliferation of IoT devices has introduced significant security vulnerabilities within public and private network infrastructures. This project presents a robust implementation of a low-cost, high-efficiency Honeypot system leveraging the ESP32 microcontroller architecture. A Honeypot, by definition, is a security mechanism set to detect, deflect, or, in some manner, counteract attempts at unauthorized use of information systems.

Our system specifically targets Intrusion Detection Patterns. By mimicking a vulnerable Access Point (AP), the device lures potential attackers into a simulated environment. This allows for the collection of forensic data, including connection attempts, MAC addresses, and DNS request logs, without compromising the actual organizational network.

02 // ADVANCED TECHNOLOGY STACK

The hardware implementation is built upon the ESP32 Dual-Core MCU, which offers integrated Wi-Fi and Bluetooth stacks. To provide local telemetry, we integrated an SSD1306 OLED Display utilizing the I2C (Inter-Integrated Circuit) communication protocol. This setup ensures high-speed data transmission between the processing core and the visual output module.

The integration of EEPROM/Flash storage allows for persistent logging of intrusion data. Even if the device loses power, the captured forensic signatures remain stored for later analysis by security professionals.

03 // STRUCTURAL ARCHITECTURE

The software layer follows an Asynchronous Event-Driven model. This is critical for preventing the system from freezing during massive connection attempts (DoS). The architecture maps the relationship between the simulated gateway and the attacker's terminal, effectively "trapping" the traffic within the Honeypot's internal DNS server.

04 // VULNERABILITY & RISK ANALYSIS

During development, we simulated multiple Attack Vectors, focusing on the "Evil Twin" vulnerability. This analysis demonstrates how easily an unsuspecting user can be redirected to a phishing portal. By capturing these interaction logs, the Honeypot serves as an educational tool to highlight the dangers of unencrypted open networks.

05 // STRATEGIC CONCLUSIONS

The ESP32 Honeypot successfully demonstrates that visibility is the first line of defense. The ability to monitor unauthorized access in real-time provides a significant tactical advantage. Our findings indicate that most automated intrusion attempts can be identified within seconds of network association.
