03. The Core Concept

بصراحة، في بداية هذا البحث، كنت أظن أن الحماية من الهكرز هي مجرد جدار ناري أو كلمة سر طويلة. لكن بعد ساعات من القراءة في "ثغرات اليوم الصفر"، اكتشفت أن التحدي الحقيقي ليس في إيقاف الفيروس، بل في معرفة أنه فيروس أصلاً قبل أن يبدأ بالتحرك.

This was my starting point for "Sentinel AI". I wanted to build something that thinks. During my time in the university library, I was asking myself: "Can we detect a thief just by the way he walks in the room?". In cybersecurity, this means looking at the Behavior of the process, not just its name.

09. Practical Implementation

لقد قررت استخدام لغة جافا سكريبت (Node.js) في هذا الجزء. بصفتي طالباً، أجد أن التعامل مع الأحداث (Events) في هذه اللغة يسهل علينا مراقبة النظام بشكل فوري. الكود التالي هو محاولة بسيطة قمت بها لبناء نظام إنذار يعتمد على "سلوك" المعالج.

// My simple security monitor logic
const os = require('os-utils');

function startMonitoring() {
  os.cpuUsage(function(v) {
    // If CPU jumps suddenly, maybe it's a virus?
    if (v > 0.90) {
      console.log("ALERT: Unusual Behavior Found!");
      stopMaliciousProcess(); // My test function
    }
  });
}

setInterval(startMonitoring, 2000); // Check every 2 seconds
