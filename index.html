01. Hardware System Integration Architecture

The architecture of the ESP32 Honeypot is a synergy between high-speed wireless processing and real-time telemetry. At the core, the ESP32 NodeMCU acts as a bridge between the physical layer and the network layer.

Key integration points include the I2C interface for the OLED display, which allows the system to remain "Headless" (not needing a PC to view logs). The wiring follows a strict protocol to ensure data integrity during packet sniffing operations.

02. Embedded Firmware & Network Logic Software

The software is written in C++ and optimized for low-latency response. The logic follows a "Capture-and-Log" loop. When a new station connects to the rogue Access Point, the DHCP server assigns an IP, and the DNS server intercepts any web request (Port 80/443).

The Captive Portal is served using an asynchronous web server, preventing the ESP32 from hanging during multiple connections. Data persistence is managed via EEPROM to keep track of total intrusion attempts.

03. Cybersecurity Attack Vector Analysis Security

This project analyzes the Evil Twin vulnerability in public infrastructures. The honeypot simulates a trusted environment to test user awareness. It demonstrates how easily an attacker can bypass standard security if the user doesn't verify the SSL certificates or the source of the SSID.

The captured data reveals that most users ignore security warnings when presented with a familiar-looking login page, highlighting the need for Multi-Factor Authentication (MFA).

04. Experimental Results & Findings Results

Final results confirm that the ESP32 is a highly capable platform for lightweight cybersecurity tools. The system maintained a 99.9% uptime during a 48-hour stress test with 5 simultaneous connections.

Conclusion: This research provides Al-Ma'moon University College with a practical baseline for future studies in embedded security and IoT threat mitigation.
