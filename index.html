03. The Core Concept

When I started this project, I was curious about why traditional antiviruses fail so often. I found that they are like a guard who only recognizes "known" criminals by their faces. But what if the criminal wears a mask? This is exactly what a Zero-Day attack does.

Fig 3.1: Visualizing the flow of an unknown attack through system memory. I noticed that while the code is hidden, the behavior is always visible.

08. Practical Logic (JavaScript)

I decided to use JavaScript (Node.js) for the practical demonstration because of its excellent event-driven nature. Below is a simplified version of the logic I wrote to monitor system spikes that might indicate an active exploit.

// My Experimental Monitor Agent
const os = require('os-utils');

function watchBehavior() {
  os.cpuUsage((v) => {
    console.log("Current System Load: " + (v * 100).toFixed(2) + "%");
    if (v > 0.92) {
      console.error("CRITICAL: Suspicious Behavioral Spike!");
      // My function to block the process
      triggerIsolation();
    }
  });
}

setInterval(watchBehavior, 1000);

This script allowed me to catch several simulated buffer-overflow attacks during my lab tests at Al-Mamoon University.
