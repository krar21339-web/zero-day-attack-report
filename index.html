03. Introduction

When I first started my second year at Al-Mamoon University College, I didn't just want to study cybersecurity; I wanted to secure Iraq's digital future. In the lab, I spend hours analyzing network traffic and I noticed a disturbing pattern: signature-based defenses are completely useless against "metamorphic" threats that have no known signature. This is known as a Zero-Day attack.

Fig 3.1: The global cyberwarfare infrastructure. The need for intelligence beyond simple rules became my obsession.

This research presents "Sentinel AI," a proactive detection agent designed to monitor system integrity by analyzing behavioral patterns, rather than looking for a file's fingerprint.

09. Practical Logic (JS Version)

For the practical component of my project, I decided to swap Python for Node.js (JavaScript) because I found its asynchronous event handling ideal for real-time monitoring. Below is a simplified, student-edition logic I developed to capture suspicious activity spikes.

// experimental system call monitor agent
const monitor = require('./ai_core');

// capturing real-time events
monitor.on('spike', (data) => {
  console.log("[ALERT] Suspicious Pattern found at PID: " + data.pid);
  core.isolateSystemProcess(data.pid);
});

// start deep behavioral inference
monitor.startDLAgent({ latency: 500 }); // inferring every 500ms

This implementation proved that even a lightweight model can resident in system memory, providing a crucial first line of defense that complements central firewalls.
