01. INTRODUCTION EMULATION OVERVIEW

EXECUTIVE SUMMARY

The primary goal of this project is to implement a robust framework for Emulating IoT Traffic using ESP32 microcontrollers and Raspberry Pi. This system simulates real-world sensor data streams to analyze network behavior under various conditions. In cybersecurity, this is essential for testing firewall resilience and detecting anomalies.

HARDWARE IMPLEMENTATION

1. ESP32 Microcontroller

The core traffic generator using integrated Wi-Fi to simulate IoT packets.

2. OLED Display (SSD1306)

Displays real-time diagnostic data, IP status, and packet transmission logs.
