Introduction

This technical report discusses the Emulation of IoT Traffic, a vital process in cybersecurity engineering. By utilizing the ESP32 microcontroller, we simulate real-world data streams to analyze how networks handle high volumes of traffic. This study is crucial for building resilient Cyber-Physical Systems (CPS) that can withstand modern digital threats and anomalies.

Technical Specs

1. The ESP32 Microcontroller (The Core): The ESP32 acts as the main computational engine for traffic emulation. With its dual-core processing capabilities and integrated Wi-Fi stack, it allows for the creation of synthetic data packets that mimic thousands of IoT sensors. It is responsible for handling the asynchronous network protocols used in our cybersecurity testing.
2. SSD1306 OLED Display (Diagnostics): This 0.96-inch display provides real-time visual telemetry. Connected via the I2C protocol, it bypasses the need for a serial monitor by displaying live network statistics, including the IP address assigned to our fake access point and the count of successfully injected traffic packets.
