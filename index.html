01 // INTRODUCTION & ABSTRACT

In the contemporary digital era, cybersecurity has transitioned from a peripheral concern to a central pillar of organizational integrity. This technical report details the design and deployment of an Active Deception Mechanism using the ESP32 microcontroller. Unlike passive defense systems, our Honeypot is engineered to actively engage with potential threats by simulating a high-value targets (HVT) within a network ecosystem.

The project focuses on the implementation of a Captive Portal and DNS Spoofing logic to redirect unauthorized traffic into a secure, isolated auditing node. This allows for real-time behavioral analysis without exposing the primary infrastructure to risk.

02 // SYSTEM ARCHITECTURE

The architecture is based on the I2C (Inter-Integrated Circuit) bus protocol, linking the ESP32 processing unit to high-fidelity monitoring modules. The logic follows an event-driven model where every connection attempt triggers a forensic signature capture.

03 // HARDWARE NODES & SCHEMATICS

The implementation utilizes the ESP32 dual-core MCU running at 240MHz. This hardware was specifically selected for its asynchronous capabilities, allowing the system to maintain a Wi-Fi beacon while simultaneously logging forensic data to internal flash memory (SPIFFS).

Fig 2.0: Structural Architecture and Data-Flow Diagram.

04 // VULNERABILITY AUDITING (THE EVIL TWIN)

A primary component of this project is the analysis of Unencrypted Rogue APs. By mimicking standard SSIDs, we demonstrate the inherent vulnerabilities in public Wi-Fi infrastructures. The Honeypot logs connection handshakes and DNS requests, providing a clear map of user exposure levels.

The data harvesting process is strictly limited to metadata analysis, ensuring that the project remains within ethical boundaries while providing deep insights into modern attack vectors.
