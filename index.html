07. Node.js Implementation

لقد اخترت Node.js لأنها لغة مرنة وتسمح لي بمراقبة النظام في الوقت الحقيقي (Real-time). الكود التالي هو نموذج أولي قمت بتطويره لمراقبة العمليات المشبوهة التي تستهلك موارد النظام بشكل مفاجئ، وهو ما قد يدل على وجود Ransomware.

const os = require('os-utils');

// Monitoring Loop
setInterval(() => {
  os.cpuUsage((v) => {
    if(v > 0.85) {
      console.log("ALERT: High Activity!");
    }
  });
}, 1000);

كما نلاحظ، الكود بسيط جداً لكنه يمثل اللبنة الأولى لنظام حماية معقد يعتمد على تحليل السلوك اللحظي للمعالج.
